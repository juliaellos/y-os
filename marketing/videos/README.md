# Vídeos do YouTube

Uma pasta por vídeo, no padrão `video-<NN>-<tema>/`. **Tudo que é daquele
vídeo mora dentro da pasta dele** — nada de vídeo vai pra `saidas/`.

## O que fica dentro de cada pasta

| Arquivo / pasta | O que é |
|---|---|
| `roteiro.md` | roteiro do vídeo |
| `titulo-descricao.md` | título, descrição do YouTube, ideia de thumbnail |
| `thumbnail/` | HTML + PNG da thumbnail |
| `materiais-gravacao/` | o que aparece na tela durante a gravação (prints, fichas, mocks) |
| `reels-cortes.md` | cortes do vídeo que viram Reels |
| `edit/` | edições da skill `/editar-video` — uma subpasta por trecho (`inicio/`, `final/`), cada uma com `transcripts/`, `animations/`, `edl.json`, `final.mp4` |

## Vídeos

- `video-01-carrossel-com-ia/` — Como criar carrossel para Instagram com IA
- `video-02-responder-avaliacoes/` — Como responder avaliação do Google Meu Negócio com IA
- `video-03-seo-com-ia/` — Por que o ChatGPT não indica o seu negócio

## Nota

Material que vale pra todos os vídeos (ex. setup de gravação, perfil do
canal) continua em `saidas/`, não aqui.
